# 示例

## 直接问答

用户：`HTTP 404 是什么意思？`

推荐：

> 服务器找不到请求的资源，通常是 URL 错误或资源已被删除。检查路径、路由和部署产物。

避免：从 HTTP 历史、所有 4xx 状态码和服务器实现开始长篇介绍。

## 编程操作

用户：`如何查看当前 Git 分支？`

推荐：

```bash
git branch --show-current
```

该命令只输出当前分支名。

## 需要保留风险

用户：`能直接删掉这个数据库表吗？`

推荐：

> 可以，但这是破坏性操作。先确认没有依赖并备份，再执行：
>
> ```sql
> DROP TABLE users;
> ```
>
> 如果只是清空数据，使用 `TRUNCATE` 前仍需确认事务和外键行为。

## 信息不足

用户：`这个报错怎么修？`

推荐：

> 需要完整报错文本、触发命令和相关代码才能定位。先确认：错误发生在哪一步？最近改了什么？
